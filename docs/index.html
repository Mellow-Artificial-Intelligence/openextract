Any file in.
A validated model out.

One function

openextract reads documents, images, audio, and video with the LLM of your choice and hands back a typed Pydantic object. Not a string. Not a dict. The model you asked for, already validated.

Install

Installs every provider SDK. For just one, use its extra, like [anthropic]. Set its API key and call extract.

pip install 'openextract[all]'

Call — extract.py 
from pydantic import BaseModel
from openextract import extract


class Invoice(BaseModel):
    vendor: str
    total: float
    currency: str


invoice = extract(
    Invoice,
    "openai:gpt-5",
    source="./invoice.pdf",  # path to the file
)

extract()What do I pass in? 
extract(schema, model, source, instructions=None, *, media_type=None)
schema
The Pydantic model you want back.
model
A pydantic-ai model string like "anthropic:claude-sonnet-5", or a configured Model.
source
Where the file is: a path like "./invoice.pdf", a pathlib.Path, or an https:// URL. Or the file's raw bytes. A string is never read as the document's text.
instructions
Optional guidance, like "Amounts are in EUR."
media_type
Only needed to override what openextract infers.
media_typeHow does it know the file type?

It takes the first answer it finds: the media_type you passed, the file extension, the URL's Content-Type header, then the file's leading bytes.

Recognized by content
PDF, PNG, JPEG, GIF, WebP, MP3, WAV, FLAC, OGG, MP4, and UTF-8 text.
exceptionsWhat happens when it fails?

Every error subclasses ExtractionError and keeps the original exception as its cause.

ModelError
The provider returns an error.
SchemaValidationError
The output doesn't match your schema.
ProviderNotInstalledError
The provider's SDK isn't installed.
ExtractionError
A URL can't be fetched.
providersWhich models can I use?

Any model pydantic-ai supports. Install the matching extra and set its API key.

pip install 'openextract[anthropic]'   # openai, google, bedrock, groq, mistral,
                                       # cohere, huggingface, openrouter, xai, all
extract_async()Is there an async version?

Yes. It takes the same arguments. Await it.

invoice = await extract_async(Invoice, "openai:gpt-5", source="./invoice.pdf")
