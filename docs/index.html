Define a Pydantic schema, choose a model, and get a validated Python object from your documents, images, audio, or video.

pip install openextract

Python 3.12+. Set OPENAI_API_KEY to your OpenAI key, then run the example below. It uses gpt-5 and makes a paid API request.

Your schema. One function.

from decimal import Decimal

from pydantic import BaseModel, Field
from openextract import extract


class Invoice(BaseModel):
    vendor: str
    total: Decimal = Field(description="Amount without currency text.")
    currency: str


source = b"""Seller: Acme Paper Co.
Total due: 120.00 USD
"""

invoice = extract(Invoice, "openai:gpt-5", source)
print(invoice.vendor)
print(invoice.total)
print(invoice.currency)

Expected output: Acme Paper Co., 120.00, USD.
