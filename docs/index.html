Quickstart

Your first
extraction.

Define an invoice with Pydantic and pass it to extract. The total comes back as a Python Decimal.

Use Python 3.12+ and set OPENAI_API_KEY to run this example.

$uv add openextract
Explore providers ↗
invoice.pyPython
from decimal import Decimal
from pydantic import BaseModel
from openextract import extract

class Invoice(BaseModel):
    total: Decimal

invoice = extract(
    Invoice,
    "openai:gpt-6.1-sol",
    "Total due: 120.00",
)
print(invoice.total)
