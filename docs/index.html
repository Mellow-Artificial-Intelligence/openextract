Define it. Extract it.

Install the OpenAI extra above with Python 3.12+, then set your OpenAI API key in the same terminal. Your account needs access to gpt-5; this example makes a paid provider request.

export OPENAI_API_KEY='your-api-key'  # macOS / Linux

On PowerShell, use $env:OPENAI_API_KEY = 'your-api-key' instead. Save the code below as first_extraction.py, then run python first_extraction.py. The fictional invoice is included as text bytes; no download is needed.

Your code 
from decimal import Decimal

from pydantic import BaseModel, Field

from openextract import extract


class Invoice(BaseModel):
    vendor: str = Field(description="Seller, not buyer.")
    total: Decimal = Field(description="Final amount due, including tax.")
    currency: str | None = Field(description="Three-letter currency code, or null if unclear.")


source = b"""INVOICE DEMO-001 (fictional sample)
Seller: Acme Paper Co.
Bill to: Northwind Studio
Paper supplies: 100.00 USD
Subtotal: 100.00 USD
Tax: 20.00 USD
Total due: 120.00 USD
"""

invoice = extract(Invoice, "openai:gpt-5", source)
print(invoice.vendor)  # str: Acme Paper Co.
print(invoice.total)  # Decimal: 120.00
print(invoice.currency)  # str | None: USD
Expected fields for this fixture
vendor
Acme Paper Co.
total
120.00 (Decimal)
currency
USD

The vendor is the seller, not the buyer. The total is the final amount due including tax, not the subtotal. Currency is a three-letter code, or None when unclear.

Schema validation checks structure and types; it does not guarantee factual accuracy. Check extracted values against your source before relying on them.

A few details.

What do I pass in? 
extract(schema, model, source, instructions=None, *, media_type=None, client=None)
schema
The Pydantic model you want back.
model
A supported provider:model string like "anthropic:claude-sonnet-5", or an openextract.Model configuration. Requests use HTTPX directly.
source
Where the file is: a path like "./invoice.pdf", a pathlib.Path, or an https:// URL. Or the file's raw bytes. A string is never read as the document's text.
instructions
Optional guidance, like "Amounts are in EUR."
media_type
Only needed to override what openextract infers. Provider and model media support varies.
client
An optional HTTPX Client, or AsyncClient for extract_async. Used only for model requests and left open.
How does it know the file type?

It takes the first answer it finds: the media_type you passed, the file extension, the URL's Content-Type header, then the file's leading bytes. Detecting a media type does not mean the chosen model can read it; input and schema support depend on the model.

Recognized by content
PDF, PNG, JPEG, GIF, WebP, MP3, WAV, FLAC, OGG, MP4, and UTF-8 text.
What happens when it fails?

Operational errors subclass ExtractionError and chain underlying errors when available. Invalid configuration or unsupported media raises ValueError; local file errors keep their standard Python types.

ModelError
A model request fails or the provider reports an HTTP or generation error. Selected upstream messages and native finish reasons are preserved.
SchemaValidationError
The output doesn't match your schema.
ProviderNotInstalledError
Deprecated compatibility export; HTTP adapters do not raise it.
ExtractionError
A URL can't be fetched.
Which models can I use?

Built-in HTTP adapters support OpenAI Responses, OpenAI-compatible Chat Completions, Anthropic, Gemini, local Ollama, Cohere, and Bedrock. Set the matching API key; provider SDKs and extras are not needed. Pydantic handles schemas and validation.

pip install openextract

Use openextract.Model for custom endpoints, headers, settings, and retry budgets. For compatible Chat Completions models, output_mode="json_schema" selects JSON Schema output. Text, images, PDF, audio, and video support depends on the adapter and model. Bedrock uses bearer tokens or your authenticated HTTPX client; automatic AWS signing is not bundled. See the provider matrix and migration guide.

Can I use decision models?

Yes. Use OpenAI Decisions with OPENAI_API_KEY, or Jev with OPENROUTER_API_KEY. Both read text and images into bool, Literal, or Enum fields. No provider extra is needed.

triage = extract(
    Triage, "openai-decisions:gpt-6-luna",
    source="./receipt.png",
)
Fields
bool, Literal, or Enum. Any other type raises a TypeError.
Questions
Each field becomes one question, phrased by its description.
bool
True when the probability of yes is at least 0.5.
OpenAI
Use openai-decisions: for Decisions; openai: keeps general extraction. Supports 1–400 fields.
Sources
Text and images only.
Is there an async version?

Yes. It takes the same arguments. Await it.

invoice = await extract_async(Invoice, "openai:gpt-5", source="./invoice.pdf")
